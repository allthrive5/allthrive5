# All Thrive Holdings – Corporate Website

A single-page responsive website for **All Thrive Holdings Pte Ltd**, a boutique advisory firm with core pillars in Capital and Strategy, focused on Vietnam.

## Overview

This is a static HTML5 website built with:
- **Tailwind CSS** (via CDN) for utility-first styling
- **Google Fonts** – Cormorant Garamond + DM Sans
- Vanilla JavaScript for scroll animations and mobile navigation
- No build tools required – open `index.html` directly in any browser

## Sections

- **Hero** – Brand statement and call to action
- **Stats Bar** – Key firm metrics
- **About** – Firm description and industry focus areas
- **Vision** – Strategic vision statement
- **Services** – Capital and Strategy service pillars

## Deployment

This site is deployed via **GitHub Pages**.

To enable GitHub Pages:
1. Go to **Settings** → **Pages**
2. Under *Source*, select `main` branch and `/ (root)` folder
3. Click **Save** – your site will be live at `https://<username>.github.io/allthrive5`

## Local Development

No dependencies to install. Simply open `index.html` in a browser.

```bash
# Optional: serve locally with Python
python3 -m http.server 8080
```
